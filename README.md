# How To Use
## Requirements 
Any linux OS supports GTK3, from PIP numpy(calculation), pillow(drawing), pycairo(for gtk3), PyGObject(for gtk3), pymupdf(for PDF drawing), setuptools(pip depency, autoinstalled)


```bash
python3 main.py
```
